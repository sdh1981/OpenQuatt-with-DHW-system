## 1. Power House thermisch model

📘 **Detail:** [power-house-thermisch-model-v0.32.md](power-house-thermisch-model-v0.32.md)

Vijf verbeteringen aan het kern-thermische model:

| # | Feature | Default | Tunbaar |
|---|---|---|---|
| 1 | Self-learning UA-coëfficiënt | uit | switch + apply button |
| 2 | Zonnewinst-correctie | uit | switch + alpha |
| 3 | Voorspellend voorconditioneren | uit | gain=0 |
| 4 | Frost-zone derating | aan, mild | max_derate=0,15 |
| 5 | Effectieve aanvoertemperatuur perf_map | aan | — |

### Bijzonderheden

- **UA-leren is verbeterd:** drempels versoepeld (room_err ≤ 0,6 K, dT_load ≥ 3 K) en gebruikt `Tr − Tout` ipv `Trsp − Tout` voor correcte heat-loss math
- **Skip-reason sensor** (`sensor.openquatt_power_house_ua_skip_reason`) toont waarom samples wel/niet worden gepakt
- **Conclusie over UA-getallen:** milde-weer-samples geven structureel **te lage UA** door zonnewinst en interne winst. Wacht op herfst/winter samples voor accurate schatting

## 3. DHW smart features

📘 **Detail:** [dhw-smart-features-v0.32.md](dhw-smart-features-v0.32.md)

Acht features voor DHW (warm water tank):

| # | Feature | Type | Default |
|---|---|---|---|
| 1 | Tariff-aware DHW scheduling | actief | uit |
| 2 | PV-zelfconsumptie DHW | actief | uit |
| 3 | Adaptive usage pattern learning | leer + actief | uit |
| 4 | Tank standby-loss tracker | observatie | aan |
| 5 | Smart legionella deferral | actief | uit |
| 6 | DHW time-to-ready sensor | observatie | aan |
| 7 | **DHW single-HP mode (Duo)** | actief | **uit** |
| 8 | Element boost configurable | actief | aan |

### Belangrijk voor Inventum Maxtank 220L

- **Tank volume** instelbaar: `number.openquatt_dhw_tank_volume` (default 220 L)
- **Legionella target range** uitgebreid tot 70°C (was 60-62) — Inventum advies is 68°C
- **Time-to-ready** gebruikt per-HP perf_map met werkelijke DHW level en Tamb

### DHW single-HP mode (NIEUW)

Het probleem dat je zag (HP1 supply >49°C, beide HPs op level 1, COP 2,1) wordt opgelost door single-HP mode:

```
switch.openquatt_dhw_single_hp_mode = aan
number.openquatt_dhw_single_hp_level_bump = 1 (default)
```

| Mode | Voorbeeld bij `dhw_hp_level=3` | COP |
|---|---|---|
| Duo (default) | HP1=3 + HP2=3 | 2,14 |
| **Single + bump 1** | Lead = level 4 | **2,53** |

Runtime-lead wisselt automatisch tussen HP1 en HP2.

### Boost element uitschakelen

Voor wie 52°C genoeg vindt zonder boost:
- `number.openquatt_dhw_hp_stop_top` → **52°C**
- `switch.openquatt_dhw_boost_after_hp` → **uit**

Legionella (1× per week) gebruikt nog wel het element — wettelijk verplicht.

## 5. Health & diagnostics

📘 **Onderdeel van:** [power-house-smart-features-v0.32.md](power-house-smart-features-v0.32.md)

### Drie health-indicatoren

| Indicator | Drempel | Wat het zegt |
|---|---|---|
| Short cycles per 24h | ≥ 8 | Mogelijk te krappe comfort_band, of mis-tuning |
| Defrost cycles per 24h | ≥ 24 | Mogelijk vuile buitenunit of lage flow |
| COP deviation (EMA τ=6u) | < -0,4 of > +1,0 | Onder-prestatie (echt zorgwekkend) of meet-artefact |

### COP-deviation asymmetrisch

Positieve deviatie (+0,5 tot +1,0) is **normaal** door perf_map Tsup-clamp:
- Bij Tsup < 35°C wordt perf_map geklemd → conservatief COP → gemeten lijkt te hoog
- v0.32 fix: alleen samples gepakt bij 35 ≤ Tsup ≤ 55°C voor schoonere EMA
- Drempel asymmetrisch: < -0,4 (echt zorg) vs > +1,0 (mogelijk meet)

### Reset-knoppen
- `button.openquatt_scop_reset_rolling_windows`
- `button.openquatt_scop_reset_lifetime`
- `button.openquatt_health_counters_reset`

## 6. Pressure protection (R32)

📘 **Detail:** [pressure-protection-v0.32.md](pressure-protection-v0.32.md)

### Tier-structuur

| Tier | Drempel | Effect |
|---|---|---|
| OK | < 38 bar | Normaal |
| Soft cap | 38-40 bar | Level −1 |
| Hard cap | 40-41 bar | Level 0 (stop) |
| HPS-mirror | ≥ 41 bar | Stop + log event |

Werkt **per HP** — alleen de HP die hoog zit wordt afgeknepen.

### Diagnostiek
- Peak EMA per HP (fouling-trend)
- Event counters per 24h en lifetime
- `binary_sensor.openquatt_pressure_fouling_warning` — actief bij peak EMA > 36 bar of ≥5 soft events/24h

### Defaults (conservatief)
- Soft 38 bar, Hard 40 bar, HPS 41 bar
- Default **aan** — geen actie nodig na flash

### Pressure tiers fysisch (R32)
- Normaal continu: 20-35 bar
- HP firmware HPS: 41-43 bar (Quatt's eigen)
- PRV (mechanisch): 45-48 bar
- Kritisch R32: 57,8 bar

## 7. Supply temp protection

📘 **Detail:** [supply-temp-protection-v0.32.md](supply-temp-protection-v0.32.md)

Per-HP cap op water-uittredetemperatuur (complementair aan `max_water_temp_limit_c` die op systeem-niveau werkt).

### Tier-structuur

| Tier | Drempel | Effect |
|---|---|---|
| OK | < soft_c (55°C) | Normaal |
| Soft | 55-58°C | Level −1 |
| Hard | ≥ 58°C | Level 0 (stop) |

**Hysterese:** cap blijft tot temp < (soft − 2 K). Voorkomt flapping.

### Verhouding tot andere caps

Thermal actuator neemt **min()** van alle caps:
```
final_cap = min(silent_cap, day_cap, pressure_cap, supply_temp_cap)
```

### Defaults
- Soft 55°C, Hard 58°C, Release 2 K, Reduce 1 level
- Default **aan**

```yaml
        device_class: monetary
        state: "{{ states('sensor.zonneplan_current_electricity_tariff') | float(0) }}"
      - name: "OpenQuatt ext electricity tariff avg24"
        unique_id: openquatt_ext_electricity_tariff_avg24
        unit_of_measurement: "EUR/kWh"
        device_class: monetary
        state: >
          {% set fc = state_attr('sensor.zonneplan_current_electricity_tariff', 'forecast') %}
          {% if fc %}
            {% set prices = fc | map(attribute='electricity_price') | list %}
            {{ (prices | sum / prices | length) | round(4) }}
          {% else %}
            {{ states('sensor.zonneplan_current_electricity_tariff') | float(0) | round(4) }}
          {% endif %}
      - name: "OpenQuatt ext grid net power"
        unique_id: openquatt_ext_grid_net_power
        unit_of_measurement: "W"
        device_class: power
        state: "{{ states('sensor.esp32_s3_zero_p1_netto_vermogen_watt') | float(0) | round(0) }}"
```

## 9. Bekende issues en bug-fixes

### v0.32 bug-fixes

1. **UA-leren werkte niet** (eerste implementatie): drempels te streng. Fix: `room_err ≤ 0,6 K`, `dT_load ≥ 3 K`, gebruik `Tr` ipv `Trsp`.
2. **Kp-observer toonde 0**: drempels te hoog en formule was wiskundig circulair. Fix: drempels versoepeld + eerlijke documentatie dat het een verificatie is.
3. **DHW boost element niet uitschakelbaar**: switch bestond al maar zat verstopt — toegevoegd aan Smart Features kaart.
4. **Pressure sensors hadden geen `id`** — toegevoegd in `oq_HP_io.yaml` zodat lambdas eruit kunnen lezen.
5. **Sorting groups niet gedefinieerd**: toegevoegd `oq_pressure_protection` en `oq_supply_temp_protection` aan `oq_webserver.yaml`.
6. **Compile-error in PH lambda**: ontbrekende `}` toegevoegd na smart features integratie.

### Pre-existing issues geadresseerd in v0.32

1. **DHW abort bij cooling-vraag** (was bug): supervisory priority order gefixt — `dhw_req` nu vóór `cooling_req` checked.
2. **Onnodige CM1-tussenstap bij CM4→CM2/CM5**: direct-transitions toegestaan vanuit alle actieve CM states.
3. **Tank-bottom sensor false-trip**: stratificatie-drempel verhoogd van +5K naar +12K, NAN behandeld als "afwezig niet defect".

## Aanbevolen volgorde van activeren

1. **Flash v0.32** — beveiligingen (pressure, supply temp) staan meteen aan, observatie features (SCOP, health, time-to-ready, live heat loss) ook
2. **Eerste week:** observeer alleen, leer wat de defaults doen
3. **DHW config:** zet `hp_stop_top` op 52°C (of jouw voorkeur) en `boost_after_hp` uit. Zet `legionella_target` op 68°C (Inventum advies)
4. **DHW single-HP mode** aanzetten als je COP < 2,3 ziet bij lage DHW level
5. **HA Smart Features pakket** plaatsen (Zonneplan + P1)
6. **Tariff-shift + PV-boost** aanzetten (DHW én Power House)
7. **Window-open detectie** aanzetten
8. **UA-leerroutine** aanzetten — wacht een week+ in mild weer, kijk wat de schatting zegt
9. **Apply UA-schatting** alleen na herfst/winter samples voor accurate kalibratie

## Veiligheid

- **Pressure protection en Supply temp protection staan automatisch aan** — geen actie nodig
- Hard caps (level 0) zitten ruim onder Quatt's eigen HPS-trip — geen valse alarms
- Slewing op alle actieve features voorkomt whipping bij meet-spikes
- Outlier rejection in alle leerroutines

## Persistentie

Alle leerstaten en counters zijn `restore_value: true`:
- UA schatting en samplecount
- DHW usage histogram (24 buckets)
- DHW tank UA leerstaat
- SCOP cumulatieven
- Health counters (lifetime)
- Pressure peak EMA en counters

Overlevd reboots en firmware updates.
